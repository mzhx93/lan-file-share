# 局域网文件共享 (LAN File Share)

一个用 Python 写的 Windows 小工具：选定本地目录或文件后，在同一局域网内启动 HTTP 服务并生成二维码，手机扫码即可在浏览器里**预览、在线播放、下载**这些内容。

## 功能特性

- 分享任意**文件夹**或**单个文件**
- 手机浏览器友好的移动端页面（目录浏览、图标、大小、时间）
- 图片/文本/PDF 直接在线预览，视频/音频在线播放（支持拖动进度、Range 断点续传）
- 单个文件直接下载、整个文件夹一键**打包下载**（zip）
- 桌面窗口显示二维码与全部访问地址，可一键复制、一键用本机浏览器打开
- 面板上可直接查看/修改服务端口（被占用时自动切换空闲端口）
- 支持中文文件名、多网卡（自动列出所有局域网 IP）
- 命令行模式：`python main.py <路径> [端口]`

## 环境要求

- Windows 10/11
- Python 3.8+（已测试 3.14），安装时勾选 **Add python.exe to PATH**

## 快速开始

1. 双击 `run.bat`（会自动安装依赖 `qrcode`、`Pillow` 并启动程序）
2. 弹窗选择要分享的文件夹或文件
3. 窗口出现二维码后，用手机微信/相机扫码，或直接在手机浏览器输入窗口中显示的地址
4. 在手机页面里点文件即可预览/播放，点“下载”保存，“打包下载”可下载整个文件夹

> 首次使用若手机打不开，通常是 **Windows 防火墙**拦截。右键 `allow_firewall.bat` → **以管理员身份运行** 放行一次即可。

## 命令行用法

```bat
python main.py                  :: 图形界面
python main.py D:\share         :: 分享目录
python main.py D:\a.mp4 8080    :: 分享单文件并指定端口
```

## 手机使用说明

- 手机与本机必须连**同一个路由器/WiFi**（不同网段无法访问）
- 扫描二维码会自动跳转到 `http://<本机IP>:8000/`
- 若二维码失效，可手动输入窗口里显示的其他 IP 地址

## 打包成 exe（可选）

```bat
build_exe.bat
```

生成 `dist\LanFileShare.exe`，可直接双击运行，无需安装 Python。

## 目录结构

```
lan-file-share/
├── main.py              # 主程序（HTTP 服务 + 二维码 + GUI）
├── requirements.txt     # Python 依赖
├── run.bat              # 一键启动脚本
├── allow_firewall.bat   # 防火墙放行脚本（管理员）
├── build_exe.bat        # PyInstaller 打包脚本
└── README.md
```

## 常见问题

- **手机打不开**：检查是否同一 WiFi；是否被防火墙拦截（运行 allow_firewall.bat）。
- **端口被占用**：程序会自动尝试 8000~8199 的可用端口。
- **二维码不显示**：依赖未装好，重新运行 run.bat。
- **分享单文件时**：扫码后直接进入该文件的预览/下载页。

> 安全提示：本工具默认**无密码**、局域网内任何设备均可访问，请仅在你信任的局域网内使用，不要分享敏感内容到公共网络。
