# lan-file-share

局域网文件/目录共享工具，提供两个版本：

| 分支 | 说明 |
|---|---|
| **windows** | Python 桌面版：运行后分享目录/文件，手机扫码预览/下载（纯局域网，无需外网） |
| **chrome** | Chrome 浏览器版：点对点(WebRTC)直传，无需安装，手机扫码下载 |

> 按需切换到对应分支查看代码。

## 获取代码

    # Windows 桌面版（Python）
    git clone -b windows https://github.com/mzhx93/lan-file-share.git

    # Chrome 浏览器版
    git clone -b chrome https://github.com/mzhx93/lan-file-share.git

---

## English

A Windows LAN file/folder sharing tool, available in two flavors:

- **windows** branch: Python desktop app (pure LAN, no internet required).
- **chrome** branch: browser-based P2P (WebRTC) version, no install needed.

    git clone -b windows https://github.com/mzhx93/lan-file-share.git
    git clone -b chrome https://github.com/mzhx93/lan-file-share.git
