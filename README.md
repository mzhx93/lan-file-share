# lan-file-share

> ⚠️ 完整项目代码在 **windows** 分支，请切换到该分支查看。

Windows 局域网文件/目录共享工具：运行后分享指定目录或文件，手机浏览器扫码即可预览/下载（Python + tkinter + 二维码）。

## 获取代码

    git clone -b windows https://github.com/mzhx93/lan-file-share.git

已克隆本仓库后，切换分支：

    git checkout windows
